What this is

An operating system whose canonical state is a typed property graph. There is no separate window list, no separate process table, no separate directory model: files, folders, applications, processes, windows, services and agents are all nodes, and everything you see is a projection of those nodes and edges.

Nothing mutates the graph in place. Every change is a labelled transaction — a batch of node and edge upserts and deletes — which is validated atomically and produces a new graph. Because the old graphs still exist, undo, redo, time travel, snapshots and cross-tab sync are consequences of the design rather than features bolted on afterwards.

The filesystem is real: files live in the browser's Origin Private File System and are indexed into the graph lazily as you expand directories. Applications run in isolated iframes and may only touch the parts of the filesystem their capability policy allows.
